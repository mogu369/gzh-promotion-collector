# 关键词与分类映射

## 默认关键词组

如果用户没给关键词，使用下面这组：

```
红包, 抽奖, 福利, 优惠, 活动, 送
```

可在调用时通过参数覆盖。

## 分类规则（process_articles.py）

文章根据**标题 + 摘要**做正则匹配，命中第一个分类即落入对应桶：

| 桶 ID      | 中文标签 | 触发关键词（不区分大小写）                          |
|------------|---------|------------------------------------|
| red_packet | 红包    | 红包 / 现金 / 补贴 / 津贴 / 返现 / 到账 |
| lottery    | 抽奖    | 抽奖 / 抽签 / 抽取 / 抽选 / 开奖 / 中奖   |
| welfare    | 福利    | 福利 / 赠送 / 免费 / 会员 / 特权 / 礼包 / 领取 / 送 |
| discount   | 优惠    | 优惠 / 折扣 / 立减 / 满减 / 秒杀 / 特价 / 降价 / 促销 |
| other      | 其他    | 以上都不命中                          |

> 优先级：red_packet > lottery > welfare > discount > other
> 即同一篇文章可能含多个关键词时，只归入优先级最高的桶。

## 官方/品牌判定

以下任一信号出现即标记 `is_official=true`：

- 标题/摘要/公众号名包含：官方、旗舰、品牌、认证、订阅号、服务号、`公众号：xxx`

> 这只是启发式，无法 100% 准确。建议人工抽查。

## 扩展建议

- 行业垂直：可加「外卖券、话费券、星巴克、瑞幸、奈雪」等品牌白名单
- 节日热点：可加「618、双11、双12、年货节、春节、情人节」等节日词
- 平台专享：可加「支付宝红包、京东豆、拼多多现金」等平台特定词

扩展时直接编辑 `scripts/process_articles.py` 顶部的 `CATEGORY_RULES` 和 `OFFICIAL_SIGNALS` 即可。
